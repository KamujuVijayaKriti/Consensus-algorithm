Consensus Algorithms in Blockchain — A Comparative Explorer

A consensus algorithm is a set of rules. Blockchain networks use these rules so that thousands of computers can agree on one true record. These computers do not know or trust each other. Without rules like this, someone could change old records or spend the same coin twice. Consensus turns many copies of a database into one record that people can trust. The algorithm a network picks changes everything about it. It changes how fast the network handles transactions. It changes how much energy the network uses. It changes how decentralized the network stays. It also changes how well the network can stop attackers. Pick an algorithm below. Every part of this page will change to match it.

06 · Layer classification

Layer 1 vs. Layer 2

Where consensus happens, and what is built on top of it.

LAYER 1

The base settlement layer

A Layer 1 blockchain runs its own consensus algorithm. It has its own validators or miners, its own native token, and its own final record of truth. Security and decentralization happen here. Every chain in this explorer's main list (Bitcoin, Ethereum, Solana, and others) is a Layer 1.

LAYER 2

Scaling on top of a base chain

A Layer 2 handles transactions away from the main chain. It uses rollups, payment channels, or side chains to do this. Then it sends a short summary back to its Layer 1 now and then. It borrows the L1's security. In return, it gives up some decentralization or trust, but it can handle far more transactions.
